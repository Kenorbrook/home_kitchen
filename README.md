# Домашнее меню

Откройте `index.html` локально или загрузите содержимое папки в GitHub Pages.

Функции:
- отдельные экраны-разделы;
- поиск по названию и ингредиентам;
- фильтры по времени и сложности;
- избранное через localStorage;
- случайный выбор;
- адаптивная мобильная верстка;
- фотографии разделов с Unsplash.

Для GitHub Pages достаточно положить `index.html` в корень репозитория и включить Pages в Settings → Pages.
